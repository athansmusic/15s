# 15 Second Mysteries ~ official homepage

A deliberately awful Geocities/MySpace-era site. Plain HTML, CSS and JS, no build step, no framework. Upload the folder anywhere that serves static files (Netlify drop, GitHub Pages, Vercel, Cloudflare Pages, an FTP server from 1999).

## Adding today's mystery (the daily job)

Open `episodes.js` and paste a new entry at the TOP of `EPISODES`:

```js
{
  n: 2,
  date: "2026-10-01",
  title: "The Case of the ...",
  blurb: "One line about the case.",
  src: "https://.../episode.mp3",   // or a YouTube link, or a Spotify episode link, or ""
},
```

- Episodes whose `date` is in the future stay hidden until that day, so you can queue the whole week up in advance.
- The home page shows the newest released episode as TODAY'S MYSTERY, with a countdown to the next one (next queued date, otherwise midnight).
- `src` decides the player: `.mp3/.m4a/.wav/.ogg` gets an audio player, a YouTube link gets an embed, a Spotify link gets the Spotify embed, anything else becomes a link, and `""` shows "the RealAudio server is down".
- The season progress bar counts released episodes against `SITE.seasonEpisodes` (90).

## Links

Also in `episodes.js`, fill in `LINKS` (Kickstarter, Spotify, Apple, YouTube, RSS, email). Anything left as `""` renders as "(coming soon!!)".

## Background music

`SITE.bgMusicYouTubeId` is looped via the YouTube IFrame API. Browsers block autoplay with sound until the visitor clicks, which is why the home page has a CLICK TO ENTER splash. Sub-pages have a PLAY button instead.

## The "LINK TO US" box

`index.html` has a textarea with `https://YOUR-URL-HERE/` in it. Replace that with the real URL once the site is live.

## Regenerating the GIFs

Every GIF in `img/` is generated by `tools/make_gifs.py` (needs Python + Pillow). Edit and rerun to tweak them.

## Pages

- `index.html` home, today's mystery, MySpace profile, listen links, webring
- `img/logo.png`, `img/logo-og.jpg`, `img/favicon.png` are web-sized copies of `15logo2.png` (the 4 MB original stays out of git)
- `guestbook.html` saves entries in the visitor's own browser (localStorage). Wire it to a real backend if you ever want a shared one.
- `404.html` point your host's 404 rule at it
